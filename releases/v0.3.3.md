## Features

- **Item Detail Screen Improvements** - New Max Width for Inner Content prevents large screen stretch on item details screen
- **Improved Sprint Completion** - Added option to move items into future sprints

## Security

- **Nonce-based Content Security Policy** - Replaced `script-src 'unsafe-inline'` with per-request cryptographic nonces, blocking injected inline scripts while preserving the theme flash prevention script
- **Command argument hardening** - Added `--` separator before file paths in Kreuzberg text extraction to prevent flag injection via crafted filenames
- **Logbook upload filename randomization** - Stored uploaded files with random hex filenames instead of preserving user-supplied names, matching the main attachment handler pattern
